# Specials and announcements

The existing `events` collection is reused for Lunch Box specials, pop-ups, limited menus, catering deadlines and community food events. Staff create and publish records in the **Specials** section of the admin dashboard; published records appear on `events.html` through a live Convex subscription.

Each record supports a title, date, start/end time, description, image, published state and display order. The page falls back to starter preview content when the new Lunch Box Convex deployment is not connected.

Future additions can extend the same collection with event type, ordering cutoff, inventory cap and a direct menu/category link. Keep private catering inquiries separate from public specials so customer data does not appear in the public event feed.
